# Vitest — current source notes

Repository: https://github.com/vitest-dev/vitest

Current README capabilities include:
- Jest-compatible mocking/stubbing/spies
- JSDOM and happy-dom
- Browser Mode for running component tests in a real browser
- Vue/React/Svelte/Lit/Marko component testing
- benchmarking
- projects
- type-level testing
- ESM-first support
- concurrency and sharding
- browser-native test execution

The current README specifies Vite >= 6.4.0 and Node >= 22.12.0.
