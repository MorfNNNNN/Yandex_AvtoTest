# OpenAPI contract-testing starter

Repository: https://github.com/virus5945/openapi-spec-starter

The repository contains:
- OpenAPI 3.0 petstore-style specification
- Spectral linting rules
- contract test script that lints, mocks and fuzz-tests
- GitHub Actions workflow on pull requests
- breaking-change guidance

This is a compact reference for combining specification linting, mocking/fuzzing and CI gates.
