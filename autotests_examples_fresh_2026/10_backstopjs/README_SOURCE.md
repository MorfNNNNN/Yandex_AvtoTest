# BackstopJS — visual regression

Repository: https://github.com/garris/BackstopJS

BackstopJS compares screenshots over time and provides:
- reference/test/diff inspection
- Chrome headless rendering
- Docker rendering
- Playwright/Puppeteer interaction support
- JUnit reports
- CI/source-control integration
- approve/reference workflow

Real workflow documented by the project:
```bash
backstop init
backstop test
backstop approve
```
