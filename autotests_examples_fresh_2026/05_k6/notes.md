# k6 current capability notes

Repository: https://github.com/grafana/k6

The current project describes k6 as a code-first load testing tool with:
- configurable load generation
- tests as code
- HTTP, WebSockets, gRPC and browser protocol support
- extensibility
- metrics storage / visualization
- CI integration

The repository currently lists v2.0.0 as the latest release (May 11, 2026).
